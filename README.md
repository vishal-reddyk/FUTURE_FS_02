# Mini CRM (MERN) - Client Lead Management System

This repository contains a full-stack Mini CRM built with React (Vite) frontend and Node/Express backend using MongoDB.

Quick start:

1. Clone repo
2. Copy `.env.example` to `.env` in `server/` and set `MONGO_URI` and `JWT_SECRET`.
3. Install server dependencies: `cd server && npm install`
4. Install client dependencies: `cd ../client && npm install`
5. Run server: `cd server && npm run dev`
6. Run client: `cd client && npm run dev`

Deployment:
- Frontend: Vercel
- Backend: Render / Railway / Heroku
- Database: MongoDB Atlas

Notes:
- This scaffold includes authentication, lead CRUD, notes, and a simple dashboard UI.
